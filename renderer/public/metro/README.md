# Images du theme Metro

Les animations du theme Metro chargent ces fichiers s'ils sont presents, et
utilisent sinon des dessins SVG integres a l'app.

Ils appartiennent aux editeurs des jeux Metro : ce dossier est ignore par git
pour qu'ils ne soient pas publies avec le depot. A recuperer depuis un
navigateur, puis a enregistrer ici sous ces noms. Ce sont des scenes
affichees en plein ecran :

| Fichier        | Contenu                                     |
| -------------- | ------------------------------------------- |
| `metro.jpg`    | Artyom dans le tunnel (activation de Metro) |
| `dark ones.jpg` | Un Dark One face a Artyom                    |
| `red star.jpg` | Fond de la Ligne Rouge                      |
| `logo.png` | Logo de la barre laterale (carre, fond transparent) |
